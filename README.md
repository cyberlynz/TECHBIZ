## Welcome

This repository documents my practical work during the TechBiz Academy Ethical Hacking Internship. I organize the learning notes and lab write-ups by week and task so a reviewer can follow what I studied, the commands I ran, the results I recorded and how I built my practice environment.

| Task | Focus | What you'll find |
